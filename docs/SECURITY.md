# Security notes
Implemented: PBKDF2 password hashing; hashed bearer tokens; per-user data isolation (404 on foreign ids); input validation (pydantic); upload type/size limits and safe filenames; SSRF guard (http/https only, public IPs only, redirects re-validated, size/time capped); references fenced as untrusted data + injection phrase screening; secret redaction in stored history; generic 500 errors; in-memory rate limit; explicit consent before any non-mock provider receives data; account/data deletion (`DELETE /me/data`); provider keys server-side only; declarative form schemas (closed field-type set, no code).

Known gaps: DNS-rebinding between check and connect (use an egress proxy / pin IP in production); rate limit is per-process memory; tokens never expire; no CSRF concerns today (bearer header) but no refresh/rotation; prompt-injection screening is heuristic, not a guarantee; data retention is a stored setting, **not enforced**; PDFs are parsed only if optional `pypdf` is installed.
